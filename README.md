# ARCHIVE.exe 3.1 — финальная версия — Цифровые воспоминания

Готовый статический проект на HTML, CSS, Vanilla JavaScript и JSON. Никакой сборки, backend, аккаунтов, внешних шрифтов, CDN или платных API.

В проекте четыре главы: **1999.exe — Последняя ночь**, **2003.exe — Неизвестный контакт**, **2007.exe — Удалённые файлы**, **2026.exe — Тот, кто сохранил**. Последняя глава раскрывает общую тайну и завершает антологию. Главы открываются последовательно: **1999 → 2003 → 2007 → 2026**. В начале доступна только 1999.exe; следующая открывается после последней сюжетной сцены предыдущей. Побеждать в мини-играх для этого не нужно.
