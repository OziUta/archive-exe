# 1999.exe — компьютер, забытый во времени

**Некоторые файлы лучше было не открывать.**

Готовая первая версия статической браузерной игры на русском языке. Вы включаете старый компьютер, исследуете HOME OS 99 и восстанавливаете историю последней ночи 1999 года. В конце — законченная история о дружбе и времени, без скримеров.

## Быстрый запуск

1. Распакуйте ZIP.
2. Откройте терминал **в папке `1999-exe`**, рядом с `index.html`.
3. Запустите простой сервер:

```bash
python -m http.server 8000
```

На Windows также можно использовать:

```powershell
py -m http.server 8000
```

4. Откройте в браузере `http://localhost:8000`.
5. Нажмите **«Включить компьютер»**. Начните с PostBox 99.

Остановка сервера — `Ctrl+C` в терминале.

**Не открывайте `index.html` двойным нажатием из проводника Windows.** ES-модулям и загрузке локальных JSON нужен HTTP-сервер. Установки npm-пакетов, сборки, API-ключей и регистрации нет. Python используется только для локальной раздачи файлов, самой игре backend не нужен.

## GitHub Pages

1. Создайте репозиторий.
2. Загрузите **содержимое** папки `1999-exe` в его корень: `index.html`, `css`, `js`, `data`, `assets` и `.nojekyll`. Можно загрузить весь проект, включая README и тесты.
3. В настройках репозитория откройте **Pages**.
4. Выберите публикацию из ветки (**Deploy from a branch**), ветку с файлами, например `main`, и папку **`/ (root)`**.
5. Сохраните настройки и дождитесь окончания публикации. Откройте адрес, показанный GitHub Pages.

Все пути относительные. Игра рассчитана в том числе на адрес вида `https://имя.github.io/1999-exe/`. Публикация на вашем аккаунте в рамках подготовки архива не выполнялась.

## Что внутри

- BIOS, приветствие, пропуск заставки и продолжение сохранённой игры.
- HOME OS 99: ярлыки, меню «Пуск», панель задач, перемещение и изменение размера окон мышью, сворачивание, разворачивание и переключение приложений. На узком экране окно занимает рабочую область.
- Проводник: восемь корневых каталогов, вложенные папки, переход по адресу, свойства, скрытые файлы, контекстное меню и защищённый архив.
- **PostBox 99:** 14 писем в четырёх папках, отметки прочтения.
- **NetChat:** три контакта, поиск по выбранному разговору, восстановленный фрагмент истории. Это сценарные записи, реальной отправки сообщений нет.
- **Блокнот:** чтение документов и личные заметки с автосохранением и выгрузкой TXT.
- **RetroWeb:** четыре вымышленных сайта, поиск, адресная строка, переходы назад и вперёд.
- **MediaPlayer 99:** три оригинальные синтезированные мелодии, пауза, переключение, громкость и декоративная визуализация ритма.
- Корзина с восстанавливаемой сюжетной запиской.
- Дневник расследования с трёхступенчатыми подсказками, пять достижений и шесть необязательных секретов.
- Пять сюжетных глав, две логические загадки и финал из четырёх эпизодов. Побеждать в мини-играх для прохождения не нужно.
- **Snake 99:** Canvas, три скорости, очки, рекорд, перезапуск, пауза и сенсорные кнопки.
- **Minefield:** Canvas, поля 8×8 / 10×10 / 12×12, безопасная первая клетка и её соседи, раскрытие пустых областей, флаги, таймер и рекорды по размерам поля.
- Настройки звука, громкости, анимаций, читаемости текста, CRT, обоев, быстрой загрузки и полного экрана, если он поддерживается браузером.
- Автосохранение, экспорт и импорт JSON с проверкой формата. Сброс и импорт требуют подтверждения внутри игры.
- 14 оригинальных SVG-иконок и две пиксельные иллюстрации. Внешние шрифты, системные файлы Windows, сторонняя музыка и логотипы не используются.

История рассчитана на неспешное чтение и исследование, ориентировочно 20–30 минут. Длительность не подтверждена пользовательским плейтестом и зависит от чтения и подсказок.

## Управление

| Действие | Управление |
| --- | --- |
| Открыть ярлык / файл | Двойное нажатие мышью; одно на телефоне; Enter после фокусировки |
| Перейти между элементами | Tab / Shift+Tab |
| Меню «Пуск» | Кнопка; Ctrl+Escape |
| Закрыть меню / диалог | Escape |
| Передвинуть окно | Потянуть заголовок |
| Развернуть окно | Кнопка □ или двойное нажатие на заголовок |
| Переключить окно | Панель задач; Alt+Tab, если сочетание передано странице |
| Закрыть окно | ×; Alt+F4, если сочетание передано странице |
| Сохранить заметки | Автоматически; кнопка; Ctrl+S внутри Блокнота |
| Snake | Стрелки / WASD / ЦФЫВ, экранные кнопки, пробел для паузы |
| Minefield | Нажатие открывает; ПКМ ставит флаг; на телефоне переключатель «Флаг» |
| Minefield с клавиатурой | Стрелки выбирают клетку, Enter открывает, F ставит флаг |

Alt+Tab и Alt+F4 часто перехватываются самой операционной системой; всегда доступны экранные кнопки. На телефоне перетаскивать окна не требуется. Меню «Пуск» прокручивается на низких экранах.

## Сохранения

Ключ `localStorage`: `home-os-99.save.v1`. Данные остаются в конкретном браузере и на конкретном адресе сайта. При переходе с localhost на GitHub Pages, смене браузера или устройства перенесите JSON через Настройки.

Сохраняются этап истории, прочитанные письма, достижения, секреты, восстановленные файлы, записи Блокнота, рекорды и настройки. Позиции открытых окон и текущие партии не сохраняются между перезагрузками. Свёрнутое окно остаётся открытым; змейка при потере активности ставится на паузу.

Повреждённая локальная запись не перезаписывается автоматически. Для продолжения используйте импорт рабочей копии или подтверждённый сброс. Если браузер запрещает хранилище, игра работает в памяти и показывает предупреждение; выгрузите JSON перед закрытием.

Виртуальный диск не читает, не удаляет и не изменяет настоящие файлы устройства. Доступ к выбранному файлу сохранения происходит только после нажатия кнопки импорта.

## Архитектура

```text
index.html               загрузочный экран и оболочка
css/style.css            ОС, приложения, мобильные правила
js/main.js               реестр приложений и общие сервисы
js/boot.js               последовательность BIOS
js/window-manager.js     окна, фокус, панель задач, жизненный цикл
js/filesystem.js         виртуальные каталоги и восстановленные файлы
js/story.js              события, главы, загадки, подсказки
js/save-manager.js       схема, валидация и хранение сохранений
js/audio.js              генерация звуков Web Audio
js/ui.js                 общие безопасные UI-функции
js/apps/                 проводник, почта, чат, браузер и другие приложения
js/games/engines.js       независимая логика обеих игр
js/games/                Canvas-интерфейсы игр
data/                   сюжет и файловая система в JSON
assets/                  оригинальные SVG
tests/                  автоматические проверки Node.js
CHECKS.md                результаты проверок и ручной чек-лист
WALKTHROUGH.md           прохождение со спойлерами
```

Приложения получают общий `ctx` с доступом к данным, сохранению, сюжету, звуку и окнам. `win.cleanup` освобождает обработчики и таймеры при закрытии; `onVisibility` реагирует на смену активности. Данные истории отделены от интерфейса. Ввод пользователя выводится через `textContent` либо экранируется.

## Проверки для разработчика

Нужен Node.js с поддержкой встроенного `node:test` (Node 20+). Для самой игры Node не нужен.

```bash
node --test tests/*.test.js
```

Либо `npm test`. Установка зависимостей не требуется.

Проверено 24 автоматических сценария, включая полный путь сюжетных состояний, форматы сохранений, игровые алгоритмы, синтаксис модулей и относительные ресурсы. Все 16 SVG прошли XML-проверку. Детали и границы проверки — в `CHECKS.md`.

## Ограничения первой версии

- Реальное браузерное прохождение, визуальная проверка и проверка на физических телефонах **не выполнялись** в среде разработки. Логические тесты не заменяют UI-плейтест.
- Звук синтезируется, фотореалистичных фотографий и озвучки нет. Эквалайзер декоративный, не анализатор звукового сигнала.
- Сетевые приложения — часть истории. Внешнего интернета, живого чата и отправки почты нет.
- Нет service worker: перезагрузка опубликованной страницы без интернета не гарантируется. Для полностью автономного запуска используйте локальные файлы с локальным HTTP-сервером.
- Не выполнялось реальное развёртывание на GitHub Pages. Относительные пути проверены программно.
- Canvas-игры поддерживают клавиатуру, но визуальное содержимое поля не имеет полного текстового аналога для скринридера.
